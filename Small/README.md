# Memory Game

Малка игра за памет на JavaScript: открий всички двойки еднакви карти.

- **Лесно:** 6 двойки (12 карти).
- **Трудно:** 12 двойки (24 карти).

Играта показва ходовете и намерените двойки. Смяната на нивото или бутонът
„Нова игра“ започват отначало с разбъркани карти. Картите могат да се избират
и с клавиатурата чрез Tab и Enter/Space.

Отвори `index.html` в браузър или изпълни от тази директория:

```sh
python3 -m http.server 8000
```

Няма външни зависимости или стъпка за компилация.
